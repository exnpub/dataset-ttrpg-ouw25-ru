# Версия 1.1.0 — Публикация Hugging Face & RAG Артефакты (2026-07-28)

## 🎉 Что нового в v1.1.0

Релиз **v1.1.0** расширяет корпус готовой RAG-инфраструктурой, предобсчитанными векторными эмбеддингами и полноценной интеграцией с **Hugging Face Hub**.

---

## 📊 Ключевые артефакты релиза

- **Hugging Face Dataset**: [`exnihilum/ttrpg-ouw25-ru`](https://huggingface.co/datasets/exnihilum/ttrpg-ouw25-ru)
- **Готовый FAISS-индекс**: `rag_index.faiss` (2.1 МБ, 1378 векторов) — мгновенный семантический поиск без вычисления эмбеддингов корпуса.
- **Векторные эмбеддинги**: `embeddings.parquet` (3.5 МБ, 384 измерения, модель `intfloat/multilingual-e5-small`) — готовы к импорту в Qdrant, ChromaDB, PGVector, Pinecone или Weaviate.
- **Интегрированный E2E-тест**: `setup_and_test.sh` — скрипт автоматизированного развёртывания и тестирования с Ollama (100% автотестов пройдены успешно).

---

## 📦 Файлы для GitHub Release (Вариант C)

Для загрузки в GitHub Release v1.1.0 подходят следующие артефакты:
1. `rag_index.faiss` — Бинарный FAISS-индекс (2.1 МБ).
2. `content/chunks/chunks.jsonl` — 1378 чанков текста для RAG (3.2 МБ).
3. `content/indexes/documents.jsonl` — 39 документов репозитория (2.5 МБ).
4. `hf_dataset_export/embeddings.parquet` — Векторный датасет (3.5 МБ).

---

## 🚀 Команда создания GitHub Release через CLI

Если у вас установлен GitHub CLI (`gh`), вы можете опубликовать релиз v1.1.0 одной командой:

```bash
gh release create v1.1.0 \
  rag_index.faiss \
  content/chunks/chunks.jsonl \
  content/indexes/documents.jsonl \
  hf_dataset_export/embeddings.parquet \
  --title "v1.1.0: Hugging Face Integration & Pre-built RAG Assets" \
  --notes-file RELEASE_NOTES.md
```
