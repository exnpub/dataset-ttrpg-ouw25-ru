# 🚀 Руководство по публикации на Hugging Face

Это руководство описывает процесс подготовки и выгрузки корпуса «Укрытое море» на Hugging Face Hub.

---

## 📋 Предусловия

Для успешной публикации вам понадобятся:

1. **Аккаунт на Hugging Face** ([зарегистрироваться](https://huggingface.co/join)).
2. **API Токен** с правами `write` ([получить здесь](https://huggingface.co/settings/tokens)).
3. **Python 3.9+** и установленные зависимости:
   ```bash
   pip install pandas pyarrow datasets huggingface-hub python-dotenv
   ```

---

## 🛠️ Настройка окружения

1. Скопируйте шаблон файла конфигурации:
   ```bash
   cp .env.example .env
   ```

2. Отредактируйте `.env`, добавив ваш токен и ID репозитория:
   ```env
   HF_TOKEN=hf_ваш_токен_здесь
   HF_REPO_ID=ваш_логин/ukrytoe-more-corpus
   HF_DATASET_VISIBILITY=private  # или public
   ```

---

## 🔄 Пошаговый процесс публикации

### Шаг 1: Подготовка данных
Скрипт сконвертирует JSONL-индексы в формат Parquet и создаст структуру датасета.
```bash
python3 scripts/prepare_for_huggingface.py
```
*Результат: файлы в папке `hf_dataset_export/`.*

### Шаг 2: Локальное тестирование
Проверьте корректность сконвертированных данных перед отправкой.
```bash
python3 scripts/test_hf_dataset.py
```
*Убедитесь, что все тесты пройдены (✅).*

### Шаг 3: Загрузка на Hugging Face Hub
Выгрузите данные и Dataset Card в облако.
```bash
python3 scripts/upload_to_huggingface.py
```
*После завершения вы получите ссылку на ваш датасет.*

---

## 📂 Структура датасета на HF

Датасет поддерживает три конфигурации (configs):

1. **`chunks`** — 1378 фрагментов для RAG и семантического поиска.
2. **`documents`** — 39 полных текстов документов в Markdown.
3. **`images`** — метаданные 132 иллюстраций.

---

## 📖 Использование датасета

После публикации любой пользователь (имеющий доступ) сможет загрузить данные одной командой:

```python
from datasets import load_dataset

# Загрузить основной конфиг (chunks)
ds = load_dataset("ваш_логин/ukrytoe-more-corpus")

# Загрузить полные документы
docs = load_dataset("ваш_логин/ukrytoe-more-corpus", "documents")
```

---

## 🔐 Безопасность и конфиденциальность

- ✅ **Никогда** не коммитьте файл `.env` в публичные репозитории.
- ✅ Используйте `.env.example` только как шаблон.
- ✅ Если вы случайно выложили токен, немедленно отзовите его в настройках Hugging Face.
