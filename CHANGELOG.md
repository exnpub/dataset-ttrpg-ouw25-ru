## [1.0.0] — 2026-07-27

### Завершено

**Этап 1. Инвентаризация и правила корпуса** ✅

- Сформирован машиночитаемый реестр 39 DOCX-документов с SHA-256 хешами
- Согласована лицензия: текстовое содержимое — Public Domain (CC0)
- Определены статусы документов, словарь типов и семантические теги
- Реализована система контроля целостности исходников

**Этап 2. Воспроизводимая первичная конвертация** ✅

- Выбран и зафиксирован Pandoc 3.10.1 как конвертер
- Реализован скрипт `scripts/build_corpus.py` для пакетной конвертации DOCX → Markdown
- Автоматизирована генерация безопасных латинских слаг-имён файлов
- Разделена автоматическая конвертация и ручная нормализация (две папки: `imported/` и `markdown/`)

**Этап 3. Нормализация Markdown и ручная вычитка** ✅

- Нормализована иерархия заголовков (H1 → H2–H4 без пропусков)
- Конвертированы таблицы в стандартный Markdown (простые таблицы) или HTML (сложные)
- Пронормализованы внешние ссылки с формата `<URL>` на `[подпись](URL)`
- Добавлены относительные пути к изображениям с содержательными `alt`-текстами
- Удалён редакторский мусор (скрытые разделы, служебные комментарии)
- Расширены неясные сокращения и игровая терминология стандартизирована
- **Все 39 документов проверены и отмечены статусом `reviewed`**

**Этап 4. Метаданные, удобные для ML** ✅

- Реализована схема YAML front matter для каждого документа
- Добавлены стабильные идентификаторы (`id`), источники (`source_path`) и хеши (`source_sha256`)
- Интегрирована система тегов и типов документов (chapter, sidebar, template, index и т. д.)
- Добавлены правила лицензирования на уровне документа и медиа-ассетов

**Этап 5. Подготовка к индексации** ✅

- Реализован скрипт `scripts/build_indexes.py` для генерации JSONL-индексов
- Созданы два слоя: `documents.jsonl` (39 документов) и `chunks.jsonl` (1378 смысловых фрагментов)
- Размер фрагментов оптимизирован: ~400–800 токенов (максимум 3200 символов по умолчанию)
- Исключены служебные комментарии, форменные поля и изображения без описания
- Каждый чанк содержит полный путь заголовков для контекста

**Этап 6. Контроль качества и выпуск** ✅ (частично)

- ✅ Автоматизирована проверка консистентности числа документов между исходниками, Markdown и индексами
- ✅ Проведена выборочная визуальная сверка структурных элементов (таблиц, изображений, ссылок)
- ✅ Семантическая проверка: структура QA-аудита прошла без расхождений
- ✅ Все документы обновлены со статусом `reviewed`
- ✅ Построены финальные JSONL-индексы с обновлёнными статусами
- ✅ Создана документация по ограничениям ИИ (`docs/AI_CONSTRAINTS.md`)
- ✅ Подготовлены скрипты валидации (`scripts/validate_corpus.py`)

### Структура корпуса (финальная версия 1.0.0)

```
docx_sources/                 # 39 неизменяемых исходников
  ├── 0. Вводная часть.docx
  ├── 1. Краткие разъяснения.docx
  └── ... (ещё 37 файлов)

content/
  ├── markdown/              # 39 нормализованных документов
  │   ├── 0-vvodnaya-chast.md
  │   ├── 1-kratkie-razyasneniya.md
  │   └── ... (ещё 37 файлов)
  ├── imported/              # прямой экспорт Pandoc (для справки)
  ├── assets/                # 132 извлечённых изображения
  ├── indexes/
  │   ├── documents.jsonl    # 39 документов с полным текстом
  │   └── images.jsonl       # 132 изображения с метаданными
  ├── chunks/
  │   └── chunks.jsonl       # 1378 семантических фрагментов
  └── manifests/
      ├── documents.json     # реестр с хешами
      └── issues.json        # открытые вопросы (все закрыты)

scripts/
  ├── build_corpus.py        # конвертация DOCX → Markdown
  ├── build_indexes.py       # генерация JSONL-индексов
  ├── validate_corpus.py     # проверка целостности
  ├── audit_conversion.py    # детальный QA-аудит
  └── index_images.py        # индексация изображений

docs/
  └── AI_CONSTRAINTS.md      # ограничения для ИИ-систем

LICENSES/
  └── TEXTS-PUBLIC-DOMAIN.md # декларация лицензии
```

### Число строк и размеры

- **Markdown-слой**: 39 документов, ~18 000 строк, ~1.2 МБ чистого текста
- **Документный индекс**: 39 записей, ~2.5 МБ JSON
- **Чанк-индекс**: 1378 фрагментов, ~3.2 МБ JSON
- **Изображения**: 132 файла (PNG, JPEG), ~450 МБ (не входит в JSONL)
- **Полный корпус**: ~470 МБ с ассетами

### Лицензирование

- **Текст**: Public Domain (CC0) — свободно использовать в ML, RAG, дообучении
- **Изображения**: авторское право (требуется отдельное согласие для переиспользования)

### Совместимость

- Python 3.9+
- Pandoc 3.10.1 (зафиксирован для воспроизводимости)
- Зависимости: только стандартная библиотека Python (json, hashlib, pathlib, re)
