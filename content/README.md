# Подготовленный корпус

Этот каталог содержит производные материалы из `docx_sources/` для чтения,
поиска и ML-задач. DOCX остаются единственным неизменяемым первоисточником.

## Слои данных

* `imported/` — прямой экспорт Pandoc в GFM с относительными путями к медиа.
* `markdown/` — нормализованный Markdown с YAML-метаданными. Все 39 документов
  проверены и имеют статус `reviewed`; внешние ссылки приведены к виду
  `[подпись](URL)`.
* `assets/` — извлечённые встроенные изображения; ссылки на них относительные.
* `manifests/` — реестр источников, хеши и открытые вопросы вычитки.
* `indexes/documents.jsonl` — документный слой для полнотекстового поиска (39 документов).
* `indexes/images.jsonl` — индекс всех 132 изображений в корпусе с метаданными.
* `chunks/chunks.jsonl` — семантические фрагменты для RAG/эмбеддингов (1378 чанков).
  Служебные комментарии и пустые поля бланков в этот слой не попадают. Оба JSONL-слоя
  содержат `license: "Public Domain"` и `license_scope: "text"`.

## Воспроизводимая сборка

Из корня проекта:

```bash
python3 scripts/build_corpus.py --refresh-markdown
python3 scripts/build_indexes.py
python3 scripts/audit_conversion.py
python3 scripts/validate_corpus.py
```

Первой командой следует пользоваться с `--refresh-markdown` только до ручной
вычитки: этот флаг перезаписывает файлы из `markdown/`. Без флага обновляются
`imported/`, вложения и манифест, но уже существующий нормализованный текст
защищён от перезаписи.

## Ручная вычитка

Перед маркировкой документа как `reviewed` нужно сверить его с DOCX, добавить
содержательные описания к изображениям, проверить таблицы/сноски/ссылки и
перевести статус в front matter. Нерешённые вопросы записываются в
`manifests/issues.json`. Все материалы корпуса лицензированы правообладателем
как `Public Domain` в части текстового содержимого, поэтому его можно
распространять и использовать в ML-задачах. Полный текст декларации — в
`LICENSES/TEXTS-PUBLIC-DOMAIN.md`; изображения требуют отдельного подтверждения
прав для мультимодального использования.
