## 📚 Как начать использовать

### Для быстрого старта:
```bash
# 1. Загрузить индексы
python3 -c "
import json
with open('content/chunks/chunks.jsonl') as f:
    chunks = [json.loads(line) for line in f]
    print(f'Загружено {len(chunks)} чанков')
"

# 2. Запустить проверку
python3 scripts/validate_corpus.py

# 3. Посмотреть документацию
cat README.md
```

### Для ML-проектов:
```bash
# Посмотреть примеры использования
cat docs/ML_USAGE.md

# Загрузить в Python:
# - documents.jsonl для полнотекстового поиска
# - chunks.jsonl для RAG с семантикой
# - images.jsonl для визуального поиска (с метаданными)
```

### Для редактирования:
```bash
# Прочитать правила
cat docs/CONTRIBUTING.md

# Отредактировать документ
vim content/markdown/ouw25-XXX.md

# Пересчитать индексы
python3 scripts/build_indexes.py

# Проверить целостность
python3 scripts/validate_corpus.py
```
